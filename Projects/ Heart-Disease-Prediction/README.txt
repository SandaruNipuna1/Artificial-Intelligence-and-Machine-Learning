-----------Heart Disease Prediction Model---------------

This project aims to build a machine learning model that predicts the risk of heart disease based on patient health data. The workflow includes preprocessing steps such as handling missing values, outlier detection, encoding categorical variables, feature selection, scaling, and dimensionality reduction (PCA). The final model is trained and evaluated to provide risk predictions.

The project is implemented in Google Colab for easy collaboration and reproducibility.

The dataset used is heart.csv, which contains medical records of patients with attributes such as age, sex, chest pain type, blood pressure, cholesterol levels, and other health indicators.

Target variable: Presence or absence of heart disease.

Features: A mix of numerical and categorical medical attributes.

---------How to Run the Code-------------

Open the project notebook in Google Colab.

Upload the dataset (heart.csv) to your Colab session.

Run the cells step by step in the following order:

Handling missing values

Outlier detection and removal

Encoding categorical features

Feature selection

Scaling numerical features

Dimensionality reduction using PCA

Model training and evaluation
