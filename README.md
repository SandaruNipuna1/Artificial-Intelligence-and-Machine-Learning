## Group Project: Heart Disease Prediction

### Project Overview

The Heart Disease Prediction project aims to develop a machine learning model that predicts the presence or absence of heart disease using patient health attributes.

The project uses the `heart.csv` dataset, containing medical attributes such as age, sex, chest pain type, blood pressure and cholesterol levels.

### Data Preprocessing

The project workflow includes:

- Handling missing values
- Outlier detection and removal
- Categorical feature encoding
- Feature selection
- Numerical feature scaling
- Principal Component Analysis (PCA)

### Machine Learning Algorithms

The project includes implementations of:

- Logistic Regression
- Decision Tree
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)
- Random Forest
- K-Means Clustering

### Model Development Workflow

1. Dataset loading and exploration
2. Data cleaning and preprocessing
3. Feature engineering and selection
4. Feature scaling
5. Dimensionality reduction using PCA
6. Model training
7. Model comparison and evaluation
8. Final model selection

### Project Tools

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib
- Google Colab
